# 第 46 课 · 双宾语代词的顺序
# Lesson 46 · Order of Double Object Pronouns

> ⏱ 30 分钟：复习 3 min · 语法 12 min · 单词 8 min · 练习 7 min
> 🔁 开始前：复习第 24 课（le, la, les）、第 25 课（lui, leur）和第 26 课（y, en）。
> 🎯 学完你能说：*Je te le donne. Je le lui ai dit. Il y en a trois. Donne-le-moi !*

---

## 1. 语法 Grammar（12 min）

### 1.1 ⭐⭐ 顺序表 / The order chart

两个代词一起出现时，按这个顺序排（都在**动词前**）：
*When two pronouns appear together, use this order (before the verb):*

| ① | ② | ③ | ④ | ⑤ | 动词 |
|---|---|---|---|---|---|
| **me** | | | | | |
| **te** | **le** | | | | |
| **se** | **la** | **lui** | **y** | **en** | + 动词 |
| **nous** | **les** | **leur** | | | |
| **vous** | | | | | |

💡 **记忆口诀**：
- *me/te/se/nous/vous* **在 le/la/les 前**：*Il **me le** donne.*
- *le/la/les* **在 lui/leur 前**：*Il **le lui** donne.*
- ***y* 在 *en* 前**，两个都在最后：*Il **y en** a.*

📌 *lui / leur* 和 *me / te* **不会同时出现**。

---

### 1.2 ⭐ 例子 / Examples

| 原句 | 代词替换 | 中文 |
|---|---|---|
| Il donne **le livre à moi**. | Il **me le** donne. | 他把书给我。 |
| Je montre **les photos à toi**. | Je **te les** montre. | 我给你看照片。 |
| Elle envoie **la lettre à Paul**. | Elle **la lui** envoie. | 她把信寄给保罗。 |
| Je prête **ma voiture à mes amis**. | Je **la leur** prête. | 我把车借给朋友们。 |
| Il **y** a **des pommes**. | Il **y en** a. | 有（苹果）。 |
| Tu **me** donnes **du pain** ? | Tu **m'en** donnes ? | 你给我点（面包）吗？ |

---

### 1.3 复合过去时、否定、原形 / PC, negation, infinitive

- **复合过去时**：代词放在**助动词前**，过去分词和前面的直接宾语**配合**
  *Je **la lui** ai donné**e**.*（*la* = la clé）我把钥匙给他了。
- **否定**：*ne* 在代词前，*pas* 在动词（助动词）后
  *Je **ne te le** dis **pas**.* · *Je **ne la lui** ai **pas** donnée.*
- **原形**：代词放在原形前
  *Je vais **te le** montrer.* 我来给你看。

---

### 1.4 ⭐ 肯定命令式：顺序不同！/ Affirmative imperative: different order!

肯定命令式里，代词放在动词**后面**，用 **连字符**，顺序变成：**直接宾语 → 间接宾语**；*me / te* 变成 ***moi / toi***：

| 陈述 | 肯定命令 | 否定命令（正常顺序） |
|---|---|---|
| Tu me le donnes. | ***Donne-le-moi !*** 给我！ | *Ne **me le** donne pas !* |
| Tu le lui dis. | ***Dis-le-lui !*** 告诉他！ | *Ne **le lui** dis pas !* |
| Tu m'en donnes. | ***Donne-m'en !*** 给我一些！ | *Ne **m'en** donne pas !* |
| Vous y allez. | ***Allez-y !*** 去吧！开始吧！ | *N'**y** allez pas !* |

📌 常用：***Vas-y !*** 去吧！加油！（*va* + *y* 时加 **s**）· ***Allons-y !*** 我们走吧！

## 2. 单词 Vocabulary（8 min）

### 给与借 Giving & lending

|---|---|---|---|
| prêter | [pʁɛ.te] | 借出 | to lend |
| emprunter | [ɑ̃.pʁœ̃.te] | 借入 | to borrow |
| rendre | [ʁɑ̃dʁ] | 还 | to give back |

## 3. 练习 Exercises（7 min）

### A. ⭐ 用两个代词替换 / Replace with two pronouns
1. Je donne le cadeau à Marie. →
2. Il montre les photos à nous. →
3. Tu prêtes ton vélo à tes amis ? →
4. Elle me donne des bonbons. →
5. Il y a du lait. →

### B. 复合过去时 / Passé composé
1. J'ai envoyé la lettre à mon père. →
2. Tu m'as rendu les livres ? →

### C. ⭐ 命令式 / Imperative
1. Donne-moi le sel. → (pronoms) ___
2. Explique la règle à Paul. → ___
3. Ne me donne pas ce livre. → ___

### D. 翻译成法语 / Translate into French
1. I told it to him.（*dire*）
2. 我给你看看。（*montrer*，用 *aller + 原形*）
3. Give them to me!（*les clés*）
4. 我早就跟你说过！

### E. 说出来 / Say it ⭐
想想你借给别人或别人送给你的东西：
> *Mon vélo ? Je le prête souvent à … Ce livre ? Mon ami me l'a offert. Les photos de vacances ? Je vais te les montrer !*

## 答案 Answers

**A.** 1. Je le lui donne. 2. Il nous les montre. 3. Tu le leur prêtes ? 4. Elle m'en donne. 5. Il y en a.

**B.** 1. Je la lui ai envoyée. 2. Tu me les as rendus ?

**C.** 1. Donne-le-moi. 2. Explique-la-lui. 3. Ne me le donne pas.

**D.**
1. Je le lui ai dit.
2. Je vais te le montrer.
3. Donne-les-moi !
4. Je te l'avais dit !
