# 第 47 课 · 复合关系代词 lequel / auquel / duquel
# Lesson 47 · Compound Relative Pronouns

> ⏱ 30 分钟：复习 3 min · 语法 12 min · 单词 8 min · 练习 7 min
> 🔁 开始前：复习第 31–32 课的 *qui, que, où, dont*，以及第 11–12 课的 *au / aux / du / des*。
> 🎯 学完你能说：*La raison pour laquelle je suis ici… Le projet auquel je pense… L'ami avec qui je voyage… Lequel préfères-tu ?*

---

## 1. 语法 Grammar（12 min）

### 1.1 ⭐ 为什么需要 lequel？/ Why do we need *lequel*?

*qui / que / où / dont* 不能放在大多数**介词**后面。介词（*avec, pour, sur, dans, sans, chez…*）+ 关系代词时：
*After most prepositions, use lequel (things) or qui (people).*

- **人** → 介词 + ***qui***：*Le garçon **avec qui** je parle.* 和我说话的男孩。
- **东西**（也可用于人）→ 介词 + ***lequel***：*Le stylo **avec lequel** j'écris.* 我用来写字的笔。

---

### 1.2 ⭐ lequel 的四个形式 / Four forms

| | 阳性 | 阴性 |
|---|---|---|
| 单数 | **lequel** | **laquelle** |
| 复数 | **lesquels** | **lesquelles** |

性数和**它代替的名词**一致：
- *La table **sur laquelle** j'ai mis mon sac.* 我放包的那张桌子。
- *Les raisons **pour lesquelles** je pars.* 我离开的原因。
- *Le quartier **dans lequel** j'habite.* 我住的街区（= *où* j'habite）。

---

### 1.3 ⭐⭐ 和 à / de 缩合 / Contractions with *à* and *de*

| | à + | de + |
|---|---|---|
| lequel | **auquel** | **duquel** |
| laquelle | **à laquelle** | **de laquelle** |
| lesquels | **auxquels** | **desquels** |
| lesquelles | **auxquelles** | **desquelles** |

**à + lequel**（动词带 *à*：*penser à, s'intéresser à, participer à, répondre à*）
- *Le projet **auquel** je pense.* 我在想的那个项目。（*penser **à** un projet*）
- *Les questions **auxquelles** il a répondu.* 他回答的问题。

**de + lequel**：只在**复合介词**里用（*à côté de, près de, en face de, au milieu de*）
- *Le parc **à côté duquel** j'habite.* 我住在旁边的那个公园。
- ⚠️ 简单的 *de* → 用 ***dont***（第 32 课）：*Le livre **dont** je parle.* 不是 *duquel*。

---

### 1.4 疑问代词 lequel ? = 哪一个？/ Interrogative *lequel ?*

- *J'ai deux robes. **Laquelle** tu préfères ?* 我有两条裙子，你更喜欢哪一条？
- ***Lequel** de ces livres est le meilleur ?* 这些书里哪本最好？
- ***Auquel** penses-tu ?* 你在想哪一个？

---

### 1.5 总结 / Summary

| 情况 | 用 |
|---|---|
| 主语 | **qui** |
| 直接宾语 | **que** |
| 地点、时间 | **où** |
| de + … | **dont** |
| 介词 + **人** | **qui**（或 lequel） |
| 介词 + **东西** | **lequel / laquelle…** |
| à + 东西 | **auquel / à laquelle…** |

## 3. 练习 Exercises（7 min）

### A. ⭐ lequel / laquelle / lesquels / lesquelles
1. La chaise sur ___ tu es assis est cassée.
2. Le bureau dans ___ je travaille est petit.
3. Les amis avec ___ je voyage sont sympas.
4. Les raisons pour ___ il est parti sont claires.

### B. ⭐ auquel / à laquelle / auxquels…
1. Le concours ___ je participe est difficile.
2. La question ___ tu penses est importante.
3. Les sujets ___ je m'intéresse sont variés.

### C. qui, que, où, dont 还是 lequel？
1. Le collègue avec ___ je déjeune est italien.
2. Le film ___ j'ai vu hier était génial.
3. L'ordinateur ___ j'ai besoin coûte cher.
4. La ville ___ je suis né(e) est grande.
5. Le stylo avec ___ j'écris est bleu.

### D. 翻译成法语 / Translate into French
1. 这就是我来法国的原因。
2. Which one do you prefer?（*la robe*）
3. 我住在一家银行对面。那家银行很大。→ 用 *en face de laquelle* 合成一句

### E. 说出来 / Say it ⭐
> *La raison pour laquelle j'apprends le français, c'est … Les sujets auxquels je m'intéresse sont … La personne avec qui je parle le plus, c'est …*

## 答案 Answers

**A.** 1. laquelle 2. lequel 3. lesquels（或 *qui*）4. lesquelles

**B.** 1. auquel 2. à laquelle 3. auxquels

**C.** 1. qui（或 *lequel*）2. que 3. dont 4. où 5. lequel

**D.**
1. C'est la raison pour laquelle je suis venu(e) en France.
2. Laquelle tu préfères ? / Laquelle préfères-tu ?
3. La banque en face de laquelle j'habite est très grande.
