🏠 法语 A0 → B2

法语 A0 → B2 学习路线 / French Learning Roadmap

每一课 = 30 分钟。先学语法，同时背这一课的核心单词。
One lesson = 30 minutes. Grammar first, plus the core words for that lesson.

每课怎么学 / How to study one lesson (30 min)

时间 Time 做什么 What to do
0–12 min 语法 Grammar：读讲解，把每个例句大声读出来 / read the rules, say every example out loud
12–22 min 单词 Vocabulary：每个词读 3 遍，在「法语助手」或 forvo.com 听真人发音，加入 Anki / say each word 3 times, check the audio, add it to Anki
22–30 min 练习 Exercises：先自己做，再看文末答案 / do them first, then check the answers at the end

背单词的规则 / Rules for learning words

  1. 名词一定连冠词一起背：背 une table，不要只背 table。
    Always learn a noun with its article.
  2. 出声读：只看不读，很快就忘。
    Say it out loud — silent reading is forgotten fast.
  3. Anki 卡片：正面写「中文 / English」，背面写「法语 + 冠词 + 音标」。每天先复习旧卡片，再学新课。
    Front: Chinese/English. Back: French + article + IPA. Review old cards every day before a new lesson.
  4. 每学完 5 课，休息一天，把这 5 课的练习重做一遍。
    After every 5 lessons, take one day to redo the exercises.

📒 词汇表和 Anki / Vocabulary lists & Anki

  • 每课的单词表在 词汇_Vocabulary/A1/、词汇_Vocabulary/A2/ 等文件夹里（例如 L01_词汇_Vocab.md），PDF 版在 PDF/词汇_Vocabulary/。
    Each lesson's word list is in 词汇_Vocabulary/, with PDFs in PDF/词汇_Vocabulary/.
  • Anki 导入文件（带发音 🔊）：词汇_Vocabulary/Anki/A1_Anki.txt（每个级别一个）。不用自己做卡片了！每张卡片的背面都会自动播放法语发音。
    1. 安装 Anki 电脑版（免费，apps.ankiweb.net），打开一次，然后关掉。
    2. 先把发音文件复制到 Anki 里（只需做一次；以后有新课再做一次）：在终端运行
      cp ~/Documents/UIUC/French/French_A0_to_B2/词汇_Vocabulary/Anki/audio/*.mp3 ~/Library/Application\ Support/Anki2/"User 1"/collection.media/
    3. 打开 Anki → 文件 File → 导入 Import → 选择 A1_Anki.txt，笔记类型选 Basic（基础），确认字段 1 = 正面（中文 / English），字段 2 = 背面（法语 + 音标 + 发音）
    4. 每张卡片都带标签，比如 French::A1::L05。每天在浏览器里搜 tag:French::A1::L05，只学当天那一课的卡片。
    5. 想在手机上学：注册 AnkiWeb（免费），在电脑上点 同步 Sync，再在手机 App 里登录同步——发音也会一起同步。
      Copy the mp3s into Anki's collection.media folder, then import A1_Anki.txt (note type Basic). Sync via AnkiWeb to use it on your phone, audio included.
  • 发音由 macOS 自带的法语语音（Thomas）生成，清楚标准，但仍是电脑合成音。遇到拿不准的词，用「法语助手」或 forvo.com 听真人发音。
    Audio is synthesized by the macOS French voice. For tricky words, check a native recording on Forvo.

诚实地说 / To be honest

  • 80 课 × 每课约 15 词 ≈ 1,200 个核心词，足够 A2–B1。B2 一般需要 3,000–4,000 词以上。
  • 所以从 A2 开始，每天还要加 10–15 分钟听/读（Easy French、innerFrench、TV5Monde），把里面遇到的新词也加进 Anki。
  • These files give you the grammar backbone and core vocabulary. Reaching B2 also needs lots of listening and reading — from A2 on, add 10–15 minutes of real French every day.

音标速查 / Quick IPA guide

本课程用国际音标（和《简明法语教程》《你好！法语》一样）。几个最重要的：
Lessons use IPA, the same as Chinese French textbooks.

音标 例词 提示 Hint
[ʁ] rouge 喉咙里的 r，像轻轻漱口 / throat R
[y] tu 嘴型说"乌"，舌头说"一"，≈ 中文「于」/ like Chinese ü
[ø] deux 嘴圆，像"饿"但更圆 / rounded "uh"
[œ] sœur 比 [ø] 嘴更张开 / more open
[ə] je 轻轻的"呃" / soft "uh"
[ɑ̃] enfant 鼻化的"昂" / nasal "ahn"
[ɔ̃] bon 鼻化的"嗡" / nasal "ohn"
[ɛ̃] vin 鼻化的"安"（嘴扁）/ nasal "ahn", flat lips
[ʒ] je 像英语 pleasure 的 s
[ʃ] chat ≈ 中文「师」的声母 / like English "sh"
[ɥ] huit 快速的 [y] / quick ü
