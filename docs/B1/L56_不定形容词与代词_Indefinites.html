1. 语法 Grammar（12 min）

1.1 ⭐ 形容词 vs 代词 / Adjective vs pronoun

很多不定词有两种形式：形容词（+ 名词）和代词（单独用）。

形容词（+ 名词） 代词（单独） 中文 English
chaque jour chacun / chacune 每个 / 每个人 each / each one
quelques amis quelques-uns / quelques-unes 几个 a few / some
plusieurs fois plusieurs 好几个 several
aucun(e) problème aucun(e) 没有一个 no / none
certain(e)s personnes certain(e)s 某些 certain / some
un(e) autre livre un(e) autre / d'autres 另一个 / 其他 another / others
n'importe quel livre n'importe lequel 随便哪个 any

1.2 ⭐⭐ 重点词详解 / Key words

① chaque（永远单数）vs chacun

  • Chaque étudiant a un livre. 每个学生都有一本书。（⚠️ 不说 chaques）
  • Chacun a son opinion. 每个人都有自己的看法。

② quelques（复数）vs quelque chose

  • J'ai quelques questions. 我有几个问题。
  • J'ai quelque chose à te dire. 我有件事要跟你说。

③ ⭐ aucun(e) = 一个都没有（和 ne 连用，几乎总是单数）

  • *Je **n'*ai aucune idée. 我完全不知道。
  • *Aucun étudiant **n'*est venu. 没有一个学生来。
  • Tu as des questions ? — Aucune. 有问题吗？——一个也没有。

④ plusieurs（永远复数，阴阳同形）

  • Je suis allé en France plusieurs fois. 我去过法国好几次。

⑤ certains / d'autres = 有些……，另一些……

  • Certains aiment le thé, d'autres préfèrent le café. 有些人喜欢茶，另一些喜欢咖啡。

1.3 ⭐ n'importe … = 随便、任何 / any…

法语 中文 例子
n'importe qui 👤 随便谁 N'importe qui peut le faire. 谁都能做。
n'importe quoi 👤 随便什么 Il dit n'importe quoi ! 他胡说八道！⭐
n'importe où 👤 随便哪里 Je peux dormir n'importe où.
n'importe quand 👤 随时 Appelle-moi n'importe quand.
n'importe comment 👤 随便怎样 Ne fais pas ça n'importe comment ! 别乱做！
n'importe quel(le) + 名词 随便哪个 n'importe quel jour 随便哪天

1.4 其他常用 / Others

  • quelque part 某处 ↔︎ nulle part 无处：Je ne le trouve nulle part. 我哪儿都找不到它。
  • même：le même livre 同一本书 · Moi-même 我自己
  • tel(le) 如此的：Je n'ai jamais vu une telle chose. 我从没见过这样的事。
  • l'un … l'autre 一个……另一个：Ils s'aiment l'un l'autre. 他们相爱。

3. 练习 Exercises（7 min）

A. ⭐ chaque 还是 chacun ？

  1. ___ matin, je bois un café.
  2. ___ a ses problèmes.
  3. Les livres coûtent 10 euros ___.

B. quelques, plusieurs, aucun(e)

  1. Je n'ai ___ problème.
  2. J'ai ___ amis français, pas beaucoup.
  3. Il a répété la question ___ fois.
  4. Tu as des nouvelles ? — Non, ___.

C. n'importe …

  1. 他什么都吃。→ Il mange ___.
  2. 随时来吧！→ Viens ___ !
  3. 别胡说！→ Ne dis pas ___ !

D. 翻译成法语 / Translate into French

  1. I have no idea.
  2. 有些人喜欢夏天，另一些人喜欢冬天。
  3. I can't find my keys anywhere.
  4. 每个人都必须参加。

E. 说出来 / Say it ⭐

Chaque jour, je … J'ai quelques … mais je n'ai aucun(e) … Certains de mes amis …, d'autres … Je pourrais habiter n'importe où, sauf …
