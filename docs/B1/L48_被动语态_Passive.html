Lesson 48 · The Passive Voice

⏱ 30 分钟：复习 3 min · 语法 12 min · 单词 8 min · 练习 7 min
🔁 开始前：复习 être 的所有时态（现在、PC、imparfait、将来）和常用过去分词。
🎯 学完你能说：La Joconde a été peinte par Léonard de Vinci. Le magasin est fermé le dimanche. Ce livre est lu dans le monde entier.

1. 语法 Grammar（12 min）

1.1 ⭐ 构成：être + 过去分词 / être + past participle

主动 Active 被动 Passive
Le chat mange la souris. 猫吃老鼠。 La souris est mangée par le chat. 老鼠被猫吃。

三步：

  1. 主动句的宾语变成主语
  2. 动词 → être（保持原时态）+ 过去分词
  3. 原来的主语前加 par（可以省略）

⚠️ 过去分词要和主语性数配合（就像形容词）：
La maison a été construite. · Les lettres sont écrites.

1.2 ⭐⭐ 各种时态 / All tenses

时态由 être 来体现：

时态 主动 被动
现在 On construit le pont. Le pont est construit.
复合过去 On a construit le pont. Le pont a été construit. ⭐
未完成过去 On construisait le pont. Le pont était construit.
将来 On construira le pont. Le pont sera construit.
最近将来 On va construire le pont. Le pont va être construit.

💡 最常用的是复合过去时被动：a été + 过去分词
La Joconde a été peinte par Léonard de Vinci. 《蒙娜丽莎》是达·芬奇画的。

1.3 par 还是 de？/ par or de?

  • 一般用 par（动作的执行者）：Il a été arrêté par la police. 他被警察逮捕了。
  • 状态、感情动词常用 de：aimer, respecter, connaître, détester, entourer, couvrir
    Il est aimé de tous. 他受到所有人的爱戴。· La montagne est couverte de neige. 山上覆盖着雪。

1.4 ⭐ 法语比英语少用被动！/ French uses the passive less than English

法语口语中常用这些方法代替被动：

① on + 主动（最常用）

  • English is spoken here. → On parle anglais ici.
  • I was told that… → On m'a dit que…（⚠️ 不能说 Je ai été dit）

② 代词式被动 se + 动词（一般规律、习惯）

  • Ça se dit. 这么说是可以的。· Ça ne se fait pas. 这样做不礼貌。
  • Le vin blanc se boit frais. 白葡萄酒要冰着喝。

⚠️ 只有直接及物动词能变被动。Je parle à Paul → ❌ 不能说 Paul est parlé。

3. 练习 Exercises（7 min）

A. ⭐ 主动变被动 / Active → passive

  1. Le professeur corrige les examens. →
  2. Victor Hugo a écrit Les Misérables. →
  3. La police a arrêté le voleur. →
  4. On construira un nouveau musée. →
  5. Tout le monde respecte ce médecin. → (de)

B. 被动 → on / On instead of the passive

  1. Le français est parlé au Québec. →
  2. La porte a été fermée. →

C. 配合 / Agreement

  1. Ces maisons ont été (construire) ___ en 1900.
  2. La lettre a été (écrire) ___ par ma grand-mère.
  3. Les enfants sont (aimer) ___ de leurs parents.

D. 翻译成法语 / Translate into French

  1. 埃菲尔铁塔建于 1889 年。
  2. Three people were injured in the accident.
  3. 这里说法语。（用 on）
  4. That's not done.（se faire）

E. 说出来 / Say it ⭐

介绍你家乡的一个地标：

… a été construit(e) en … par … Il/Elle est visité(e) par … touristes chaque année. On dit que …
