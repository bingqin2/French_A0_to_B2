## 1. 语法 Grammar（12 min）

### 1.1 几点了？/ What time is it?

问：***Quelle heure est-il ?*** [kɛ.lœ.ʁɛ.til] 几点了？
（口语：***Il est quelle heure ?***）

答：***Il est*** + 数字 + ***heure(s)***
- *Il est **une heure**.* 一点。（单数 *heure*）
- *Il est **deux heures**.* 两点。（复数 *heures*）
- *Il est **midi**.* 中午 12 点。· *Il est **minuit**.* 半夜 12 点。

👂 **heure** [œʁ] 以元音开头，前面的数字要**联诵**，读音会变：
*Numbers link with heure(s):*

| 时间 | 读音 | | 时间 | 读音 |
|---|---|---|---|---|
| une heure | [y.nœʁ] | | six heures | [si.zœʁ] |
| deux heures | [dø.zœʁ] | | sept heures | [sɛ.tœʁ] |
| trois heures | [tʁwa.zœʁ] | | huit heures | [ɥi.tœʁ] |
| quatre heures | [ka.tʁœʁ] | | neuf heures | [nœ.vœʁ] ⚠️ f → [v] |
| cinq heures | [sɛ̃.kœʁ] | | dix heures | [di.zœʁ] |
| | | | onze heures | [ɔ̃.zœʁ] |

### 1.2 分钟、刻、半 / Minutes, quarters, half

| 时间 | 法语 | 中文 |
|---|---|---|
| 8:05 | huit heures **cinq** | 八点五分 |
| 8:15 | huit heures **et quart** [e kaʁ] | 八点一刻 |
| 8:30 | huit heures **et demie** [e də.mi] | 八点半 |
| 8:45 | neuf heures **moins le quart** [mwɛ̃ lə kaʁ] | 差一刻九点 |
| 8:50 | neuf heures **moins dix** | 差十分九点 |
| 12:30 | midi **et demi** | 中午十二点半 |

💡 **和中文很像**：*et quart* = 一刻，*et demie* = 半，*moins* = 差。
*moins = minus, just like Chinese 差.*

**24 小时制**：在火车站、电视、学校等**正式场合**，法国人常用 24 小时制，直接读数字：
- 18 h 30 → *dix-huit heures trente*
- 21 h 15 → *vingt et une heures quinze*（注意 *une*，因为 *heure* 是阴性）

**上午 / 下午 / 晚上**（12 小时制时用）：
- *huit heures **du matin*** 早上 8 点
- *trois heures **de l'après-midi*** 下午 3 点
- *huit heures **du soir*** 晚上 8 点

---

### 1.3 "在几点" / At what time?

用 **à** + 时间：
- *Le cours commence **à** neuf heures.* 课九点开始。
- ***À quelle heure** tu arrives ?* 你几点到？

---

### 1.4 星期 / Days of the week

| 法语 | 音标 | 中文 |
|---|---|---|
| lundi | [lœ̃.di] | 星期一 |
| mardi | [maʁ.di] | 星期二 |
| mercredi | [mɛʁ.kʁə.di] | 星期三 |
| jeudi | [ʒø.di] | 星期四 |
| vendredi | [vɑ̃.dʁə.di] | 星期五 |
| samedi | [sam.di] | 星期六 |
| dimanche | [di.mɑ̃ʃ] | 星期日 |

**规则 Rules：**
1. **小写**（和英语不同！）*lundi*，不写 *Lundi*。*Lowercase — unlike English.*
2. 都是**阳性**。
3. ⭐ **加不加 le，意思不一样：**
   - ***lundi***（不加）= **这个**星期一：*Lundi, je vais à Paris.* 这周一我去巴黎。
   - ***le lundi***（加 le）= **每个**星期一：*Le lundi, je fais du sport.* 我每周一做运动。

---

### 1.5 月份 / Months

| 法语 | 音标 | | 法语 | 音标 |
|---|---|---|---|---|
| janvier 1月 | [ʒɑ̃.vje] | | juillet 7月 | [ʒɥi.jɛ] |
| février 2月 | [fe.vʁi.je] | | août 8月 | [u] 或 [ut] |
| mars 3月 | [maʁs] ⚠️ s 发音 | | septembre 9月 | [sɛp.tɑ̃bʁ] ⚠️ p 发音 |
| avril 4月 | [a.vʁil] | | octobre 10月 | [ɔk.tɔbʁ] |
| mai 5月 | [mɛ] | | novembre 11月 | [nɔ.vɑ̃bʁ] |
| juin 6月 | [ʒɥɛ̃] | | décembre 12月 | [de.sɑ̃bʁ] |

- 也是**小写**、**阳性**。
- "在……月"用 **en**：*en janvier*、*en août*。
- ⚠️ *sept*（7）里的 p 不发音，但 *septembre* 里的 p **要发音**！

---

### 1.6 ⭐ 日期 / Dates

**结构：le + 数字 + 月份**（顺序和中文**相反**：先日后月）
*Format: le + day + month (day before month).*

- *le 3 novembre* [lə tʁwa nɔ.vɑ̃bʁ] 11 月 3 日
- *le 14 juillet* 7 月 14 日（法国国庆节）
- ⚠️ **1 号**用 ***premier***（第一）：*le **1er** mai* = *le **premier** mai*
- 其他日子都用普通数字，**不说** *le deuxième*、*le troisième*（和英语 *3rd* 不同）

**问日期 / Asking the date：**
- ***Quelle est la date aujourd'hui ?*** 今天几号？
- ***On est le combien ?***（口语）
- 回答：***On est le 3 novembre.*** / ***Aujourd'hui, c'est lundi 3 novembre.***

**年份**：*2026* = ***deux mille vingt-six***（*mille* = 千，不加 s）
- *Je suis né(e) **en** 2005.* 我出生于 2005 年。（*deux mille cinq*）

## 2. 单词 Vocabulary（8 min）

## 3. 练习 Exercises（7 min）

### A. 几点了？/ What time is it?（用 12 小时制）

2. 7:15
3. 10:30
4. 5:45

6. 9:50

### B. 用 24 小时制读 / Read in 24-hour time
1. 14 h 20
2. 18 h 45
3. 21 h 00

### C. lundi 还是 le lundi？
1. ___, je vais chez le médecin.（这个周一，只一次）
2. ___, je fais du sport.（每周一）
3. ___, nous allons à la plage.（这个周六）

### D. 用法语写日期 / Write the date
1. 1 月 1 日
2. 7 月 14 日
3. 12 月 25 日
4. 8 月 3 日

### E. 翻译成法语 / Translate into French
1. What time is it?
2. 课在早上 9 点开始。
3. Today is Wednesday.
4. 我的生日是 5 月 1 日。（生日 = *mon anniversaire*）
5. Tonight, I'm going to the restaurant.
