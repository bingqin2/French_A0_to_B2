## 1. 语法 Grammar（12 min）

### 1.1 每个名词都有"性" / Every noun has a gender

法语名词分 **阳性 masculine (m.)** 和 **阴性 feminine (f.)**。
人很好理解：*un homme*（男人）是阳性，*une femme*（女人）是阴性。
但**东西也有性**，而且大多没有道理可讲：
*Every French noun is masculine or feminine — even objects, usually for no logical reason.*

| 阳性 m. | 阴性 f. |
|---|---|
| **un** livre 一本书 / a book | **une** table 一张桌子 / a table |
| **un** stylo 一支笔 / a pen | **une** chaise 一把椅子 / a chair |
| **un** sac 一个包 / a bag | **une** maison 一座房子 / a house |

💡 **用中文理解**：这就像中文的**量词**。你说"一**本**书""一**张**桌子"，不会说"一张书"。量词是跟名词一起记的，没有为什么。法语的 *un / une* 也一样：**名词和冠词一起背**。
*Think of Chinese measure words: you learn 本 together with 书. Learn un/une together with each noun.*

---

### 1.2 不定冠词 / Indefinite articles = "a / an / some"

| | 单数 singular | 复数 plural |
|---|---|---|
| 阳性 m. | **un** [œ̃] | **des** [de] |
| 阴性 f. | **une** [yn] | **des** [de] |

- **un / une** = 英语 *a / an*，中文"一个、一本、一张……"
- **des** = 英语 *some*，中文"一些"。阳性、阴性的复数**都用 des**。

例句 Examples（大声读！Read aloud!）：
- *C'est **un** garçon.* 这是一个男孩。/ *This is a boy.*
- *C'est **une** fille.* 这是一个女孩。/ *This is a girl.*
- *Ce sont **des** livres.* 这些是（一些）书。/ *These are books.*

> 📌 **C'est** [sɛ] = 这是 / this is（后面接单数）
> 📌 **Ce sont** [sə sɔ̃] = 这些是 / these are（后面接复数）

⚠️ **和英语不同**：英语常省略 *some*（*These are books.*），但**法语不能省略冠词**，必须说 *Ce sont **des** livres.*
*English drops "some"; French never drops the article.*

---

### 1.3 复数：加 -s，但 -s 不发音 / Plural: add -s (silent)

- un livre [livʁ] → des livre**s** [livʁ]：读音完全一样！
- une fille [fij] → des fille**s** [fij]

👂 所以听的时候，要靠冠词 **un / une / des** 来判断单数还是复数。
*The -s is silent. You hear the plural only from the article.*

---

### 1.4 联诵 / Liaison

**des** 和 **un** 后面如果是元音（或哑音 h）开头的词，最后的辅音要和后面的词连读：
*When the next word starts with a vowel sound, link the final consonant to it.*

| 写法 | 读音 | 说明 |
|---|---|---|
| des‿amis | [de.za.mi] | s 读成 [z] |
| des‿hommes | [de.zɔm] | h 不发音，所以也连读 |
| un‿ami | [œ̃.na.mi] | n 和 a 连在一起 |
| des livres | [de livʁ] | 辅音开头，**不**连读 |

---

### 1.5 猜性别的小技巧 / Tips to guess the gender

这些规律**大多数时候**成立，但有例外。最可靠的方法还是**带冠词背**。
*These patterns usually work — but always learn the article anyway.*

| 结尾 Ending | 通常是 Usually | 例子 |
|---|---|---|
| -tion, -té, -ure, -ette | 阴性 f. | une question, une université, une voiture |
| -ment, -age, -eau, -isme | 阳性 m. | un appartement, un fromage, un bureau |

例外 Exceptions：*une page*（一页）、*une image*（一幅图）、*l'eau*（水，阴性）。
