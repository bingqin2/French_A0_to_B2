# 第 68 课 · 简单过去时（认读）passé simple
# Lesson 68 · The *Passé Simple* (Reading Only)

> ⏱ 30 分钟：复习 3 min · 语法 12 min · 单词 8 min · 练习 7 min
> 🔁 开始前：复习常用过去分词（*eu, été, fait, pris, vu, venu, mis*）——简单过去时的形式和它们很像！
> 🎯 学完你能读懂：*Il était une fois une princesse… Elle ouvrit la porte et vit un loup. Ils se marièrent et eurent beaucoup d'enfants.*

---

## 1. 语法 Grammar（12 min）

### 1.1 什么是简单过去时？/ What is it?

- 意思**和复合过去时一样**（完成的过去动作）
- 只用于**书面叙事**：小说、童话、历史书、正式传记
- 法国人**说话从来不用**——你也**不需要会写**，**认得出来**就行！
*Same meaning as the passé composé, but only in literary/historical writing. You only need to recognize it.*

| 口语、日常写作 | 文学、历史 |
|---|---|
| *Il **a ouvert** la porte.* | *Il **ouvrit** la porte.* |
| *Napoléon **est né** en 1769.* | *Napoléon **naquit** en 1769.* |

---

### 1.2 ⭐ 三组词尾 / Three sets of endings

实际上你最常看到的是 **il / elle** 和 **ils / elles** 两种形式：
*In practice you'll mostly see il/elle and ils/elles.*

| | **-er 动词**：-a 型 | **-ir / -re 动词**：-i 型 | **-u 型**（很多不规则） |
|---|---|---|---|
| | parler | finir / prendre | avoir / vouloir |
| je | parl**ai** | fin**is** / pr**is** | e**us** / voul**us** |
| tu | parl**as** | fin**is** / pr**is** | e**us** |
| **il / elle** | **parla** | **finit / prit** | **eut** / **voulut** |
| nous | parl**âmes** | fin**îmes** | e**ûmes** |
| vous | parl**âtes** | fin**îtes** | e**ûtes** |
| **ils / elles** | **parlèrent** | **finirent / prirent** | **eurent** / **voulurent** |

💡 **识别窍门**：
- ***-a*** 和 ***-èrent*** 结尾 → -er 动词（*il chanta, ils chantèrent*）
- ***-it*** 和 ***-irent*** 结尾 → -ir/-re 动词（*il partit, ils partirent*）
- ***-ut*** 和 ***-urent*** 结尾 → -u 型（*il fut, ils furent*）

⚠️ 陷阱：*il finit* 既可能是**现在时**也可能是**简单过去时**——看上下文！

---

### 1.3 ⭐⭐ 必须认识的不规则形式 / Irregulars you must recognize

| 原形 | il / elle | ils / elles | 中文 |
|---|---|---|---|
| **être** | **fut** | **furent** | 是 |
| **avoir** | **eut** | **eurent** | 有 |
| **faire** | **fit** | **firent** | 做 |
| **aller** | **alla** | **allèrent** | 去 |
| **venir** | **vint** | **vinrent** | 来 |
| **voir** | **vit** | **virent** | 看见 |
| **dire** | **dit** | **dirent** | 说 |
| **prendre** | **prit** | **prirent** | 拿 |
| **mettre** | **mit** | **mirent** | 放 |
| **pouvoir** | **put** | **purent** | 能 |
| **savoir** | **sut** | **surent** | 知道 |
| **vouloir** | **voulut** | **voulurent** | 想 |
| **devoir** | **dut** | **durent** | 必须 |
| **naître** | **naquit** | **naquirent** | 出生 |
| **mourir** | **mourut** | **moururent** | 死 |
| **vivre** | **vécut** | **vécurent** | 生活 |
| **tenir** | **tint** | **tinrent** | 握住 |

⚠️ *il vit* 可能是 *voir* 的简单过去时（看见），也可能是 *vivre* 的现在时（生活）！

---

### 1.4 在故事中：简单过去时 + 未完成过去时 / In stories

和 PC + imparfait 的分工**一样**（第 28 课）：
- **imparfait** = 背景、描述
- **passé simple** = 推动情节的事件

> *Il **faisait** nuit. La forêt **était** silencieuse. Soudain, le petit garçon **entendit** un bruit. Il **se retourna** et **vit** un loup.*
> 那时是夜晚，森林里很安静。突然，小男孩听到一个声音。他转过身，看见一只狼。

## 3. 练习 Exercises（7 min）

### A. ⭐ 找原形 / Find the infinitive
1. il fut → 2. elle eut → 3. ils firent → 4. il vint → 5. elle prit → 6. ils virent → 7. il put → 8. elles allèrent → 9. il naquit → 10. il mourut →

### B. 改成复合过去时 / Change to passé composé
1. Il ouvrit la porte. →
2. Elle partit sans rien dire. →
3. Ils se marièrent en 1890. →
4. Victor Hugo naquit en 1802. →

### C. 阅读 / Read（翻译成中文）
> *Il était une fois un roi qui avait trois filles. Un jour, il les appela et leur dit : « Je suis vieux. » La plus jeune se mit à pleurer. Le roi fut très ému.*
