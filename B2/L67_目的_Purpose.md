# 第 67 课 · 目的 pour que, afin de…
# Lesson 67 · Expressing Purpose

> ⏱ 30 分钟：复习 3 min · 语法 12 min · 单词 8 min · 练习 7 min
> 🔁 开始前：复习第 64 课 1.4（主语相同 → 原形）。
> 🎯 学完你能说：*J'apprends le français pour travailler en France. Je parle lentement pour que tu comprennes. Afin d'éviter les embouteillages, partez tôt. Je me suis caché de peur qu'on me voie.*

---

## 1. 语法 Grammar（12 min）

### 1.1 ⭐⭐ 两种结构 / Two structures

| 主语相同 → **介词 + 原形** | 主语不同 → **连词 + que + 虚拟式** |
|---|---|
| ***pour** + inf.* | ***pour que** + subj.* |
| ***afin de** + inf.*（正式） | ***afin que** + subj.* |
| ***de peur de / de crainte de** + inf.* | ***de peur que / de crainte que** (ne) + subj.* |
| ***en vue de** + inf. / nom* | — |
| ***dans le but de** + inf.* | — |

- *Je travaille **pour gagner** de l'argent.*（我工作，我赚钱）
- *Je travaille **pour que** mes enfants **aillent** à l'université.*（我工作，孩子上大学）
- *Je me dépêche **de peur d'**être en retard.* 我赶快，怕迟到。
- *Je ferme la fenêtre **de peur que** le chat (ne) **sorte**.*

---

### 1.2 ⭐ 正面目的 / Positive purpose

| 表达 | 语域 | 例句 |
|---|---|---|
| **pour** | 中性 | *Je suis venu **pour** te voir.* |
| **afin de / afin que** | 正式、写作 | ***Afin de** réduire la pollution, il faut…* |
| **dans le but de** | 正式 | *Il a créé cette association **dans le but d'**aider les enfants.* |
| **en vue de** | 正式 | *Il économise **en vue d'**acheter une maison.* · ***en vue des** élections* |
| **de façon à / de manière à** + inf. | 方式+目的 | *Parle fort **de façon à** être entendu.* |
| **de sorte que / de façon que** + subj. | 方式+目的 | *Il explique **de sorte que** tout le monde **comprenne**.* |

⚠️ ***de sorte que* + 直陈式** = 结果（所以）：*Il a plu, **de sorte que** le match **a été** annulé.*
***de sorte que* + 虚拟式** = 目的（以便）。

---

### 1.3 负面目的（避免）/ Negative purpose (avoiding)

- ***pour ne pas*** + 原形：*Je pars tôt **pour ne pas** rater le train.*（⚠️ *ne pas* 都放在原形前面！）
- ***pour éviter de*** + 原形 / ***pour éviter que*** + 虚拟式：*Pour éviter les embouteillages…*
- ***de peur de*** / ***de peur que***

---

### 1.4 疑问 / Asking about purpose

- ***Pour quoi faire ?*** 做什么用？（⚠️ 两个词，≠ *pourquoi*）
- ***Dans quel but ?*** 出于什么目的？
- ***À quoi ça sert ?*** 这有什么用？⭐ → ***Ça sert à*** + 原形：*Ça sert à ouvrir les bouteilles.*

## 3. 练习 Exercises（7 min）

### A. ⭐ 原形还是 que + 虚拟式？
1. Je t'appelle pour (je / te dire) ___ bonjour.
2. Je t'appelle pour (tu / savoir) ___ la nouvelle.
3. Il faut agir afin de (on / protéger) ___ l'environnement.
4. Le gouvernement agit afin que (les citoyens / vivre) ___ mieux.

### B. 负面目的 / Negative purpose
1. Je me lève tôt. Je ne veux pas être en retard. → (pour ne pas)
2. Je parle bas. J'ai peur de réveiller le bébé. → (de peur de)

### C. 翻译成法语 / Translate into French
1. What's it for?
2. 为了减少污染，应该乘坐公共交通。（*afin de*）
3. I'm saving money with a view to buying a car.
4. 我慢慢说，好让大家都听懂。（*de sorte que*）

### D. 说出来 / Say it ⭐
> *J'apprends le français afin de … Mon objectif, c'est de … Pour que ma famille …, je … Pour ne pas oublier les mots, je …*
