## 强调表达 Emphatic expressions

| 法语 French | 音标 IPA | 中文 | English | 备注 Notes |
|---|---|---|---|---|
| **C'est moi qui…** | [sɛ mwa ki] | 是我…… | It's me who… |  |
| **Ce n'est pas moi !** | [sə nɛ pa mwa] | 不是我！ | It wasn't me! |  |
| **C'est pour ça que…** | [sɛ puʁ sa kə] | 就是因为这个…… | That's why… |  |
| **C'est là que…** | [sɛ la kə] | 就是在那里…… | That's where… |  |
| **C'est alors que…** | [sɛ.ta.lɔʁ kə] | 就在那时…… | It was then that… |  |
| **Voilà ce que…** | [vwa.la sə kə] | 这就是…… | That's what… |  |
| **Ce qui compte, c'est…** | [sə ki kɔ̃t sɛ] | 重要的是…… | What matters is… |  |
| **même** | [mɛm] | 甚至 | even |  |
